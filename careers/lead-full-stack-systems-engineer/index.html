Lead Full-Stack Systems Engineer (TypeScript / Node / React)

OPEN Full-Time 100% Remote (Worldwide) 4+ Years

Role Overview

We are looking for a Lead Full-Stack Systems Engineer to own core digital systems, high-concurrency Node.js services, and high-performance React frontends that power mission-critical client products.

Key Responsibilities

  • Lead end-to-end full-stack feature architecture from database schema design to responsive, accessible UI components.
  • Build high-throughput RESTful and GraphQL APIs with strict TypeScript typings, caching layers, and latency <100ms.
  • Enforce code craftsmanship, automated testing (unit, integration, e2e), and continuous deployment standards.
  • Mentor mid-level engineers, conduct rigorous pull request reviews, and drive architectural decision records (ADRs).
  • Partner with product managers and UX designers to rapidly iterate on complex data-dense web workflows.

Required Skills & Experience

  • 4+ years of professional full-stack development with TypeScript, React, and Node.js.
  • Advanced mastery of modern state management, React Server Components (Next.js/Vite), and web performance optimization.
  • Strong relational database design (PostgreSQL) and caching strategies (Redis).
  • Demonstrated ability to write clean, maintainable, modular, and test-driven code (Jest, Vitest, Playwright).
  • Deep understanding of browser performance, Core Web Vitals, and responsive UI layout.

Preferred Skills & Bonus Points

  • Experience with event-driven architectures (Kafka, RabbitMQ, SQS).
  • Familiarity with Tailwind CSS, Radix UI, Framer Motion, and design system authoring.
  • Hands-on exposure to Docker containerization and cloud deployments.

Qualifications

  • B.S. in Computer Science, Software Engineering, or related discipline, or equivalent practical experience.
  • Portfolio of delivered full-stack production systems or high-impact open-source contributions.
